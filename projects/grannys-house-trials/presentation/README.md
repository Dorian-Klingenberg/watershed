# Watershed family presentation

Open [`index.html`](./index.html) in a browser. It works offline; use the
on-screen buttons or the left/right arrow keys to move through the slides.
For a handout, use the browser's Print command and save as PDF.

The deck is intentionally a short, visual introduction. Its concept art and map
studies are exploratory, while the prototypes are small experiments—not a
finished game. The live-demo steps and fallback are in
[`demo-notes.md`](./demo-notes.md). Optional background is in
[`appendix.md`](./appendix.md).

The `images/` folder contains only the pictures used by this presentation.
